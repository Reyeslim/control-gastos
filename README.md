# Control de gastos personales

Aplicación web interactiva para gestionar ingresos y gastos mensuales, diseñada como ejercicio práctico para integrar los fundamentos de JavaScript con la manipulación del DOM.

## Qué se practica en este proyecto

- **Fundamentos:** Variables (`let` y `const`), tipos de datos, objetos, arrays y estructuras condicionales (`if / else if / else`).
- **Métodos de array:** Iteración y transformación de datos con `.forEach()`, `.filter()`, `.reduce()` y `.push()`.
- **Manipulación del DOM:** Selección de elementos (`querySelector`), modificación de contenido (`textContent` e `innerHTML`), creación dinámica de nodos (`createElement`) y gestión de eventos (`addEventListener`).
- **Buenas prácticas:** Validación de formularios mediante salida temprana (`return`) y refactorización bajo el principio DRY (_Don't Repeat Yourself_).

## Estructura del proyecto

```text
├── index.html   # Estructura base y contenedores con sus identificadores
├── styles.css   # Estilos y diseño responsivo con Flexbox
└── script.js      # Lógica de la aplicación dividida por pasos
```

## Cómo ejecutarlo

1. Descarga o clona los archivos en una misma carpeta.
2. Abre `index.html` directamente en tu navegador (o usando la extensión _Live Server_ en VS Code).
3. Abre las herramientas de desarrollador (`F12`) si quieres inspeccionar los datos en la consola mientras pruebas la interfaz.
